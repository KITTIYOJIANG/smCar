麦轮底盘原地转测试小软件

启动方法
1. 解压压缩包。
2. 双击 turn_test_gui.bat。
3. 如果电脑没有 pyserial，脚本会自动尝试安装。

电脑要求
1. Windows。
2. 已安装 Python 3。
3. 小车固件已经烧录支持 turn / imu / yaw / vel 串口命令的版本。

基本测试流程
1. 选择小车的 COM 口，例如 COM10。
2. 点击“连接”。
3. 把车放在十字中心，车头指向“前”。
4. 点击“IMU 静止校准”，校准期间不要碰车。
5. 点击“应用参数”。
6. 点击“左转 90°”或“右转 90°”。
7. 观察串口日志里的 target / yaw / err，并记录中心偏移方向和距离。

常用按钮
左转 90°：发送 turn 90。
右转 90°：发送 turn -90。
左转 180°：发送 turn 180。
右转 180°：发送 turn -180。
Yaw 归零：发送 yaw reset。
停止：发送 s，紧急停机。
状态：发送 status。

补偿参数说明
坐标定义：
vx 右为正，单位 mm/s。
vy 前为正，单位 mm/s。

当前实测推荐值：
左 vx = -10
左 vy = 10
右 vx = -25
右 vy = 0
turn min = 120
turn max = 150

如果左转后仍向原右后偏移，优先微调左 vx/lvy，例如 -12/12 或 -15/15。
如果左转后变成原左前偏移，说明补偿过大，把左 vx/lvy 往 0 收。
如果右转后仍向原右偏移，继续减小右 vx，例如 -30。
如果右转后变成原左偏移，说明补偿过大，把右 vx 往 0 收。

安全提醒
测试前确认小车四周没人和线缆不会卡住轮子。
任何时候异常，点“停止”。
